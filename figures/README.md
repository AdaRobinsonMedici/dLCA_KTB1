# Figure exports

The repository banner and Mermaid diagram explain the framework; they are not numerical article figures.

Final article figures should be added as matched image/data pairs after the authoritative run is reconciled. Supplied presentation filenames are not treated as confirmed manuscript figure numbers. Draft PowerPoint/Visio sources and their embedded metadata are not uploaded in this build.

| Figure subject | Required source evidence |
| --- | --- |
| Framework architecture | Final caption and implemented-versus-future scope |
| KTB1 process diagram | Exact benchmark revision, source attribution and reuse permission |
| Electricity generation and price | Verified UTC background panels and plot date windows |
| Foreground and background impact profiles | Confirmed units, mappings and LCIA method |
| Annual schedules and cumulative results | Reconciled scenario outputs and denominators |
| Independence/sensitivity results | Finite, validated diagnostic exports and parameter definitions |

For every published numerical plot, store a readable image, the permitted source table, and the generating notebook section or script. Record the commit and method in an export manifest. Avoid publishing a graph that cannot be traced to its data.
